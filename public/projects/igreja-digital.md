# Igreja Digital Central

Plataforma descentralizada para gestão de igrejas, composta por dois repositórios complementares: um servidor central (igreja-digital-central) e um cliente mobile (igreja-central-mobile), integrados via Supabase totalmente self-hosted.

- Cliente e servidor operando de forma independente, conectados via Supabase
- App mobile em React Native para membros e gestores
- Painel central em React para administração
- Infraestrutura 100% self-hosted, sem dependência de serviços pagos na nuvem
- Integração em tempo real via Supabase (banco de dados, autenticação e storage)

Projeto colaborativo que demonstra como construir plataformas distribuídas com frontend mobile + painel web + backend descentralizado.
