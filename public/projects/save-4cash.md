# Save 4 Cash - Economia Inteligente

Aplicativo de controle e economia financeira pessoal, desenvolvido com React Web e empacotado para mobile via Capacitor, com sistema de monetização por anúncios e opção de remoção mediante pagamento.

- App web com React e TypeScript, empacotado como app mobile com Capacitor
- Interface simples e prática para controle de gastos e metas de economia
- Sistema de anúncios integrado para monetização
- Opção de compra para remover anúncios (in-app purchase)
- Funciona em iOS e Android a partir da mesma base de código

Demonstra uma estratégia moderna de desenvolvimento cross-platform: um único codebase React compilado para múltiplas plataformas via Capacitor.
