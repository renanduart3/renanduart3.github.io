# Venda Mobile Inteligente

Aplicativo mobile completo para gestão de vendas, com sistema de pagamento de mensalidades, controle de assinaturas via Supabase e deploy automatizado com Fastlane.

- Gestão de vendas, clientes e produtos com interface intuitiva
- Sistema de assinaturas com validação e controle de pagamentos via Supabase
- Relatórios e estatísticas de vendas em tempo real
- Sincronização de dados via Supabase (banco de dados + autenticação)
- Deploy automatizado para iOS e Android com Fastlane (Ruby)
- Plano premium com funcionalidades avançadas para profissionais

Demonstra como construir um produto mobile completo com monetização por assinatura, desde o app até o pipeline de publicação automatizado nas lojas.
