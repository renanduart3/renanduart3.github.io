# Mega Powar - Simulador de Loteria

Aplicação web simples e divertida construída com React que simula o sorteio da Mega-Sena, gerando jogos aleatórios para o usuário.

- Interface interativa para geração de palpites da Mega-Sena
- Geração aleatória de números dentro das regras do jogo
- Projeto leve e focado em usabilidade
- Desenvolvido com React para praticar componentes e estado

Uma ótima demonstração de como React pode ser usado para criar aplicações de entretenimento de forma rápida e eficiente.
