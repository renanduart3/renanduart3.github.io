# WordPress com Docker

Projeto de referência que demonstra como executar o WordPress em um ambiente totalmente containerizado com Docker.

- Configuração completa via `docker-compose.yaml`
- WordPress + banco de dados MySQL isolados em containers
- Ambiente reproduzível e portável, sem dependências no host
- Ótimo ponto de partida para desenvolvimento local ou deploy em VPS

Demonstra como a conteinerização simplifica o setup de ambientes CMS complexos, garantindo consistência entre desenvolvimento e produção.
