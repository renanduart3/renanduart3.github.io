# MSBuild - Sistema de Testes e Exemplos

Projeto educativo que demonstra como o MSBuild funciona na prática, com sistemas de testes e exemplos funcionais em .NET.

- Projeto de console demonstrando o processo de build
- Módulo financeiro (financas) como caso de uso real
- Componentes compartilhados (shared) para reuso entre projetos
- Exemplificação do pipeline de build e suas etapas

Ideal para quem quer entender como o MSBuild orquestra a compilação, linking e geração de artefatos em soluções .NET.
