## Visão Geral do Projeto

Faith Scroll é uma aplicação para leitura diária, devocionais e gerenciamento de planos de leitura. Permite criar listas, marcar progresso e compartilhar passagens.

## Funcionalidades Principais

- Planos de leitura personalizados
- Devocionais e conteúdos diários
- Marcação de progresso e lembretes
- Compartilhamento nas redes sociais

## Implementação Técnica

Construído como uma aplicação responsiva (Astro/React/Vue dependendo da stack), com CMS simples para gestão de conteúdos e suporte a notificações push via serviço de backend.

## Instalação & Setup

Confira o README do repositório para passos de setup. Geralmente:
- Clonar
- Instalar dependências
- Configurar provider de notificações
- Rodar build/local

## Status do Projeto

Em progresso — integração com notificações e melhorias no editor de devocionais.
