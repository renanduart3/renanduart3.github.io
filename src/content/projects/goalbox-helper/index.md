## Visão Geral do Projeto

Goalbox Helper é uma aplicação para planejar, priorizar e acompanhar metas pessoais e profissionais. Possui integração com notificações, tags e sprints para organizar entregas.

## Funcionalidades Principais

- Criação e acompanhamento de metas
- Organização por tags e sprints
- Relatórios de progresso
- Notificações e lembretes

## Implementação Técnica

Stack leve com foco em UI/UX e persistência local/sincronizada. Pode incluir integração com serviços externos para notificações e autenticação social.

## Instalação & Setup

Consulte o README no repositório. Passos típicos:
- Clonar o repositório
- Instalar dependências
- Configurar variáveis (API/Notificações)
- Rodar em modo dev

Em progresso — aprimoramentos de UX e sincronização cross-device.
