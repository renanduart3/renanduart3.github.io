## Visão Geral do Projeto

Venda Mobile é um aplicativo pensado para vendedores e pequenas equipes comerciais, oferecendo cadastro de produtos, controle de pedidos, histórico de clientes e integração com serviços de pagamento. O objetivo é oferecer uma solução leve e rápida para operações de vendas em campo.

## Funcionalidades Principais

- Cadastro e gerenciamento de produtos
- Criação e envio de pedidos
- Histórico e perfil de clientes
- Relatórios básicos de vendas
- Integração com gateways de pagamento (opcional)

## Implementação Técnica

O app foi desenvolvido com foco em performance mobile-first, utilizando frameworks modernos (ex: React Native / Flutter conforme a stack do projeto) e seguindo boas práticas de armazenamento offline/sincronização para operação em áreas com conectividade intermitente.

## Instalação & Setup

Siga as instruções do repositório para rodar localmente. Normalmente:
- Clonar o repositório
- Instalar dependências
- Configurar variáveis de ambiente para APIs e gateways
- Rodar em modo dev e emular dispositivo

## Status do Projeto

Em progresso — melhorias de UX e integração de pagamentos em andamento.
